Entry for the make.fun bounty "The Battery's Last Text to Its Charger": a small Python program that writes one line to `entry.txt` — a dying phone battery's final text message to the charger it waited for all day, equal parts breakup text and last will, with the power bank cast as the one who actually showed up.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/output python3 main.py
```
